# App Store Screenshot Package

Final upload candidates are in:

- `final/iphone-6-5/` - App Store Connect iPhone 6.5-inch landscape PNGs, `2778 x 1284`
- `final/iphone-6-9/` - 6.9-inch iPhone landscape PNGs, `2868 x 1320`
- `final/ipad-13/` - true full-screen 13-inch iPad landscape PNGs, `2752 x 2064`

1. `01-title-screen.png`

Recommended iPad upload order:

1. `01-title-screen.png`

Notes:

- Use `final/iphone-6-5/` for the current App Store Connect iPhone screenshot box if it asks for `2778 x 1284` or `2688 x 1242` landscape screenshots.
- Keep `final/iphone-6-9/` as the newer-device reference set, but do not upload it into a 6.5-inch screenshot slot.
- Use the first three files in `final/ipad-13/` for iPad. They are real iPad Simulator captures, not phone screenshots placed inside an iPad canvas.
- `02b-how-to-play-v3-controls-approved.png` is the approved V3 controls how-to image adapted for the iPhone screenshot slot.
- `reference/` keeps supporting App Store/Game Center art, including the 1024 app icon, Game Center challenge images, and the original approved V3 how-to asset.
- `raw/` keeps the simulator captures used to build the final set.
- `preview/` contains small JPG contact sheets for quick review only. Do not upload preview JPGs to App Store Connect.
